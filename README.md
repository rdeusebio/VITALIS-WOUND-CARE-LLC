# Vitalis Wound Care LLC

> **Healing that stays close to home.**  
> Specialized mobile wound care with compassionate clinical support across Chicago, Illinois, and surrounding communities.

---

## 🌟 Overview
Vitalis Wound Care LLC is dedicated to providing compassionate, hospital-grade in-home wound management, pain control, and advanced tissue therapies. This repository hosts the official landing page and client consultation scheduling interface.

## ✨ Features
- **Modern Responsive Design**: Clean healthcare interface built with vanilla HTML5, CSS3, and JavaScript (no heavy runtime dependencies).
- **Interactive Booking Flow**: Modal-based scheduling system with customizable dates, time slots, and quick email dispatch.
- **Service Highlights**:
  - Chronic Wound Management (debridement, bioengineered skin substitutes, Wound VAC)
  - Pain Management Strategies
  - Clinical Assessment & Documentation
- **Direct Clinic Contact**: Direct telephone and email dispatch links.
- **Custom Brand Favicon**: SVG & embedded data URI icon for dark and light browser tabs.

## 🚀 Quick Start / Deployment
Since this site is built with standard HTML/CSS/JS:
- **Local Preview**: Double-click `index.html` to open directly in any web browser.
- **GitHub Pages**: Go to **Settings > Pages** in your GitHub repository and select the `main` branch to host live for free.
- **Netlify / Vercel**: Drag and drop the folder or connect your Git repository.
